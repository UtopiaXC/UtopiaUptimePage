# Utopia Uptime Page

Languages: **English** | [简体中文](README_zh_CN.md) | [繁體中文](README_zh_TW.md) | [日本語](README_ja.md)

A website availability monitoring dashboard frontend, supporting [Uptime Robot](https://uptimerobot.com/) and [Uptime Kuma](https://uptimekuma.org/), pure static deployment.  
You can visit the [DEMO](https://status.utopiaxc.cn/).

## 1. Features
- **Multi-Source Support**: Aggregate monitors from multiple Uptime Robot accounts or Uptime Kuma instances into a single dashboard.
- **Visual Config Generator**: Includes a built-in visual generator (`config-generator.html`) to easily create your configuration file without touching code.
- **Kuma Multi-functional Database Script**: Includes an optional Python FastAPI bridge (`Utopia Kuma Server`) to solve Kuma's CORS issues and fetch extended historical data directly from Kuma's database.
- **i18n Support**: Full native support for English, Simplified Chinese, Traditional Chinese, and Japanese.

## 2. Deployment

### 2.1 Frontend deployment
1. Download the latest compiled distribution from the [Releases](https://github.com/UtopiaXC/UtopiaUptimePage/releases) page.
2. Extract and serve the `/dist` folder with any static web server (Nginx, Vercel, GitHub Pages).

### 2.2 Config generation and setting
1. Open `<your-domain>/config-generator.html` in your browser.
2. Follow the visual instructions to generate your config.
3. Save the result as `config.js` and place it in the root directory.

### 2.3 Utopia Kuma Server (Optional)
This optional server is designed to act as a bridge for Uptime Kuma instances. It solves CORS issues when making requests to the public API and, when running in database mode, it reads Kuma's database directly. This bypasses the default 100-heartbeat limit, allowing the dashboard to display an extended range of historical availability data (e.g., 7 days or more).

#### 2.3.1 Run directly
Ensure you have created and configured your `.env` file first (copy `.env.example` to `.env`).
```bash
cd server
pip install -r requirements.txt
python server.py
```

#### 2.3.2 Run via Docker
To run via Docker, simply pull the pre-built image and mount your Uptime Kuma data directory:
```bash
docker run -d \
  --name utopia-server \
  -p 55520:55520 \
  -v /path/to/uptime-kuma/data:/data \
  utopiaxc1025/utopia-kuma-server
```
